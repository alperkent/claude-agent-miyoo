Self-hosted build (alperkent fork).

- Built by GitHub Actions in this repository, from this source, with no change to what the app does on the Miyoo.
- Updates come from this repository's releases, not the original author's.
- No built-in relay: the app uses the relay in `config/server.txt` on the SD card (or the one this build was made with).

**Install:** download `ClaudeAgent-v1.0.1.1.zip` below and extract it to the root of the SD card. See `docs/SELF_HOSTING.md`.
